Onde o Google ADK entra

Neste laboratório, o ADK é a camada que transforma a definição do agente em uma execução organizada: modelo + instruções + tools + sessão + loop de execução.

Usuário
↓
Backend
↓
LlmAgent — definido pelo Google ADK
↓
Gemini
↓
FunctionTool / RAG / MCPToolset

O arquivo mais importante

src/adk/agent.ts

const agent = new LlmAgent({
  name: "ada_assist_adk",
  model: "gemini-2.5-flash",
  instruction: "...",
  tools: [
    knowledgeTool,
    campaignTool,
    metricsTool,
    cancelTool,
    mcpToolset
  ]
});

O que o ADK está abstraindo?

  • Runner e loop de execução do agente.
  • Chamadas de tools.
  • Sessões.
  • Eventos de execução.
  • Orquestração do fluxo agente → modelo → tool → modelo.
  • Integração com MCP através de MCPToolset.

Importante

O modo padrão deste laboratório é mockado. Assim você pode estudar a arquitetura sem consumir Gemini. Quando quiser experimentar o ADK de verdade, coloque MOCK_MODE=false e uma GOOGLE_API_KEY.
